# Día Laboral

Android app to track daily work records.

## Features
- Arabic and Spanish interface with an in-app language switch.
- Box categories A, B, C, D and the ability to add more.
- Editable hourly rate, initially €9.30.
- Daily records, box counts, hours worked and cumulative total.
- Export records to an Excel-compatible .xls file.
- Custom launcher icon.

## Download APK
Every push to main starts the GitHub Actions workflow **Build Día Laboral APK**. Open the Actions tab and download the **Dia-Laboral-APK** artifact from a successful run.
